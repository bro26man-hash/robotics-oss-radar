### 2. [AtsushiSakai/PythonRobotics](https://github.com/AtsushiSakai/PythonRobotics)
**⭐ 30,531 stars | Language: Python | Last updated: Sept 17, 2026**

*Python sample codes and textbook for robotics algorithms — the go-to educational resource for robotics engineers.*

**Recent Development Highlights:**
- **Dependency maintenance** — latest commits bump CodeQL (4.37.9), ruff (0.16.5), and SciPy (1.18.1) (Sept 2, 2026)
- The codebase itself is stable and mature; recent activity is focused on security and lint tooling rather than new algorithms
- Still one of the most-starred robotics educational repos on GitHub

**🎙️ Potential Episode Topics:**
- "Why PythonRobotics remains the #1 teaching tool for robotics algorithms — and what's next"

**Recent Development Highlights:**
- **Apollo 11.0 bev+occ** (`539f546`, Feb 27, 2026) — new bird's-eye-view + occupancy perception stack, a major perception upgrade
